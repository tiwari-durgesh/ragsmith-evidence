# Pilot failure summary — provisional, single-annotator

**18 independent source facts and 36 derived cases; no statistical or performance
claims are made from this pilot.** Facts share nine contexts; statistical
independence is not established. The frozen pipeline ran once without tuning.
LLM cross-check was not run; no human inter-annotator agreement is claimed.

There were 27 baseline/case label mismatches across 18 distinct cases:

| Baseline | Aggregate case-label mismatches |
| --- | ---: |
| Extraction only | 18 |
| Binary sufficiency | 9 |
| Graded sufficiency | 0 |

Case identifiers, per-case human labels, human notes, raw answers/citations and
private label files are intentionally omitted from this public copy and its
published history. They remain in the original local repository/history.
These aggregate descriptive counts do not establish answer/citation correctness,
novelty, generalization or reliability. A second human annotator for 30–50
questions remains required before any paper results.

See the [aggregate results table](pilot36-results.md). Public/local commit
correspondence is recorded in [publication history](public-publication-history.md).
